# Social Media App

A modern, responsive social media application inspired by Reddit, built with **React, TypeScript, and Tailwind CSS**. Users can create and interact with posts, join conversations, manage their profiles, and stay connected through notifications.
https://social-media-app-nine-pied.vercel.app
## ✨ Features

- **Authentication** – User registration and login.
- **Post Management** – Create, edit, and delete posts.
- **Community Interaction** – Like, bookmark, and share posts.
- **Comments & Replies** – Join discussions and reply to other users.
- **User Profiles** – View profiles and follow other users.
- **Notifications** – Stay updated on social interactions.
- **Responsive Design** – Optimized layouts for desktop, tablet, and mobile.
- **Dark & Light Mode** – Switch between themes.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/Om4r-Y4sser/social-media-app.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd social-media-app
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
